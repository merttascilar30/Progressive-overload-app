# Overload

Salon antrenmanlarını takip eden, mobil öncelikli ve çevrimdışı çalışan ilerleme uygulaması. React 19, Vite, Tailwind CSS ve Dexie (IndexedDB) kullanır.

## Komutlar

- `npm run dev`: geliştirme sunucusu
- `npm test`: Vitest testleri
- `npm run build`: üretim derlemesi
- `npm run lint`: oxlint

## Özellikler

- Rutinler ve hareket havuzundan ya da elle hareket ekleme
- Set kaydı (ağırlık, tekrar, RIR) ve geçmişi görüntüleme/düzenleme
- Brzycki 1RM ile bir sonraki set için dinamik hedef önerisi
- Çevrimdışı çalışma (PWA, IndexedDB)
